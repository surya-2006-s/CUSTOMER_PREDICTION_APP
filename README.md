# Customer Churn Prediction Website

A machine learning web app that predicts whether a customer is likely to churn (leave a service) based on their details.

## Project Structure

- `model/`     — ML training script and saved model
- `backend/`   — Flask API that serves predictions
- `frontend/`  — HTML/CSS/JS user interface

## Tech Stack

- **ML:** Python, pandas, scikit-learn
- **Backend:** Flask
- **Frontend:** HTML, CSS, JavaScript

## How It Works

1. User enters customer details in the web form.
2. Frontend sends data to the Flask backend.
3. Backend loads the trained model and predicts churn.
4. Result is shown back to the user.
